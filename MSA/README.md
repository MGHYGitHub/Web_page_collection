# MSA 数据分析中心

这是一个离线优先的 Minitab 风格数据分析页面，入口为 `index.html`。页面依赖仓库内的 SheetJS 文件，不需要 CDN 或后端服务。

## 支持的输入

- **CGK**：第 1 行为规格列名，例如 `ISO(0±50)`，后续行为重复测量。每一列独立计算均值、标准差、Cg、Cgk、偏倚和判定。
- **重复性 Xbar-S**：第 1 行为列名，后续为测量值；子组大小默认 5，可在页面调整。
- **相关性**：表头后按“三坐标、AOI、极差”顺序排列，选择 PCS 数量后计算拟合线、R、R-Sq 和差值。
- **GRR**：第 1 行表头，第 2 行规格上限，第 3 行规格下限；第 4 行起为产品 SN、操作员和规格测量值。
- **偏倚**：A 列测量值，B 列参考平均值，C 列可选差值；未提供 C 列时自动计算 A-B。
- **线性**：A 列测试项、B 列位置号、C 列测量值、D 列标准值。

可导入 `.xlsx`、`.xls`、`.csv`、`.txt`，也可直接粘贴制表符数据。导出报告会生成原始数据和已完成模块的结果子表；页面 Canvas 图表同时提供对应的结果明细，便于在 Excel 中继续制作原生图表。

## 统计口径

页面按 Minitab 常见工程口径实现：CGK 使用完整规格带宽的 20% 作为量具误差带，Xbar-S 使用 A3/B3/B4 控制图常数，GRR 使用方差分量近似法。结果适合快速复核和报告整理，正式放行时应与企业 Minitab 模板的抽样、重复次数和 ANOVA 设置逐项核对。
