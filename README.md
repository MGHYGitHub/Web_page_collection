# MGHY · 本地网页工具集

无需构建的静态工具集，包含可自定义的首页门户、工时记录、CPK 分析、Mapping 矩阵管理、在线计时器和浏览器站点监控。

## 本地运行

在项目根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8765/index.html`。优先使用本地 HTTP 服务，直接打开文件时部分浏览器会限制请求与本地存储。

## 页面与配置

| 功能 | 入口 | 维护位置 |
| --- | --- | --- |
| 首页 | `index.html` | `links.js` 配置预置卡片，`portal.js` 管理交互，`style.css` 管理样式 |
| 工时 | `工时/index.html` | `holiday-config.js` 配置日期，`holiday-settings.js` 管理编辑器，`worktime-polish.css` 统一深色兼容 |
| CPK | `CPK/CPK3.1.0.html` | 页面内分析与导出逻辑；同一行数据按 1 PCS 统计总体误测率 |
| Mapping | `Mapping/Mapping3.1.0.html` | 页面内矩阵逻辑；模板为同目录 `TIA.xlsx` |
| 计时器 | `在线计时器/在线计时器.html` | `timer.js` 管理计时和恢复，`timer.css` 管理明暗主题与适配 |
| 站点监控 | `站点监控/站点监控.html` | `monitor.js` 管理检测、历史与设置 |

首页添加的卡片保存在当前浏览器，可导出 `links.js` 后替换网站根目录文件。默认卡片仍以 `links.js` 为准。

工时页脚的日历按钮连续点击两次可打开节假日设置；支持切换年份月份、返回今天、点击或右键设置日期、编辑或导入 JSON、导出完整 `holiday-config.js`。发布配置时替换同名文件，保留所有年份与分类函数。

## 数据与计算

- 工时记录、卡片、计时器记录、监控历史使用当前浏览器的本地存储，不会自动同步到其他浏览器或域名。清理浏览器数据前请先使用各工具的备份或导出功能。
- 工时保持深色主题；Datalink 导出的固定 28 列结构与顺序保持兼容。夜班休息字段为 01:00–03:00。
- 五险一金与个税是按公开政策比例进行的简化估算，页面注明估算时间和参考来源；没有实时官方政策接口。实际扣款受缴费基数、险种档次、累计预扣及专项扣除等影响。
- 站点监控仅在页面开启时检测。跨域请求通常只能收到 opaque 响应，无法读取 HTTP 状态；蓝色“状态受限”不代表已确认站点正常。浏览器 HTTPS 页面无法直接检测 HTTP 地址。
- 计时器刷新后恢复已保存进度并保持暂停；暂停和继续分别计入实际运行片段，倒计时结束保留记录。快捷键：空格开始/暂停，C 记录，M 毫秒，S 声音，1/2/3 模式，Shift+R 重置；输入框内不触发快捷键。

## 发布与检查

将完整目录发布到静态服务器，保留中文子目录以及相对路径。更新时包含新增的 `portal.js`、`工时/holiday-settings.js`、`工时/worktime-polish.css`、`工时/icons.css`、`站点监控/monitor.js` 和 `在线计时器/timer.js`、`timer.css`，不要只上传 HTML。工时的 Excel 库与图标字体复用 `CPK/js/xlsx.full.min.js` 和 `CPK/fonts/`，请一起保留。

使用已安装的 Node.js 运行：

```powershell
node scripts/check-site.mjs
git diff --check
```

检查脚本验证本地 HTML/JS 语法、重复 ID 和 HTML/CSS 资源路径；它不能替代浏览器实际操作、Excel 导出或不同系统的视觉验收。维护时同时检查桌面和手机宽度，确认菜单与弹窗对比度、表格横滚、已有记录恢复，以及计算结果与导出口径一致。
